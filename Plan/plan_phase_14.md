# Phase 14: Bildstil-Avatar

## Ziel

Eine stilisierte, bildbasierte Avatar-Inszenierung als 3D-Szene bereitstellen.

## Umfang

- Eine eigenständige Komposition aus 3D-Elementen und lokalen Texturen erstellen.
- Bewegungs- oder Leuchteffekte auf die Animationsspur reagieren lassen.
- Keine geschützten Assets aus *System Shock 2* übernehmen; die Referenz beschreibt nur die gewünschte Wirkung.

## Abhängigkeit

Phase 08.

## Akzeptanzkriterien

- [x] Die Darstellung ist eine geschichtete Three.js-3D-Szene aus extrudierten Flächen und Meshes, ohne 2D-Sprites.
- [x] Linsenlicht und Segmente reagieren auf SAPI-Visemereignisse.
- [x] Geometrie und Code sind lokale Assets; fremde Spiel-Assets werden nicht verwendet.
- [x] Assetverfügbarkeit und typisierter Wechsel sind getestet und in der `README.md` dokumentiert.
