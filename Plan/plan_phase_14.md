# Phase 14: Bildstil-Avatar

## Ziel

Eine stilisierte, bildbasierte Avatar-Inszenierung als 3D-Szene bereitstellen.

## Umfang

- Eine eigenständige Komposition aus 3D-Elementen und lokalen Texturen erstellen.
- Bewegungs- oder Leuchteffekte auf die Animationsspur reagieren lassen.
- Keine geschützten Assets aus *System Shock 2* übernehmen; die Referenz beschreibt nur die gewünschte Wirkung.

## Abhängigkeit

Phase 08.

## Akzeptanzkriterien

- [ ] Die Darstellung ist eine 3D-Szene und verwendet keine 2D-Sprites.
- [ ] Mindestens ein Element reagiert sichtbar auf Sprechereignisse.
- [ ] Alle Assets liegen lokal vor.
- [ ] Beispiel und Verhalten sind getestet und in der `README.md` dokumentiert.
