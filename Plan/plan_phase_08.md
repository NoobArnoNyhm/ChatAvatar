# Phase 08: Three.js-Grundszene

## Ziel

Eine lokale Three.js-Szene im WebView2 anzeigen und aus WPF initialisieren können.

## Umfang

- Three.js lokal einbinden.
- Kamera, Beleuchtung, Renderer und Größenanpassung implementieren.
- Einen kleinen typisierten Nachrichtenkanal zwischen WPF und Webansicht festlegen.

## Abhängigkeit

Phase 07.

## Akzeptanzkriterien

- [ ] Die Szene rendert ein sichtbares 3D-Testobjekt.
- [ ] Fenstergrößenänderungen passen die Darstellung an.
- [ ] WPF kann eine definierte Initialisierungsnachricht senden.
- [ ] Darstellung und Tests verwenden keine Netzwerkressourcen.
- [ ] Die Einbindung ist in der `README.md` dokumentiert.
